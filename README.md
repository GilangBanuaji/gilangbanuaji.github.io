# Gilang Banuaji — Portfolio

Professional Cloud & Infrastructure Engineer portfolio built with React, Vite, JavaScript, and CSS.

## Development

```bash
npm install
npm run dev
```

For a production check, run `npm run build` followed by `npm run preview`.

## Resume

The downloadable resume lives at `public/resume/Gilang-Banuaji-Resume.pdf`. Keep this filename when replacing it with a newer version.

## GitHub Pages

Pushes to `main` trigger `.github/workflows/deploy.yml`. In repository settings, select **Pages → Source → GitHub Actions**. The resulting user page is published at https://gilangbanuaji.github.io.
